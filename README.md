# 无人机三维航迹规划与避障仿真系统 v2.0（迭代二）

浏览器端单无人机三维航迹规划、动态避障与在线重规划仿真最小闭环。
规划计算运行在 **Web Worker**，不阻塞渲染；引擎为 **Three.js / WebGL2**。

## 技术栈

| 层次 | 选型 |
| --- | --- |
| 语言 | TypeScript 5.6（strict） |
| 渲染 | three 0.169 / WebGL2（自动回退 WebGL1） |
| 前端 | Vue 3.5（`<script setup>`） |
| 状态 | Pinia |
| 并行 | Web Worker（Vite `?worker` 独立分包） |
| 构建 | Vite 5 |
| 测试 | Vitest（node 算法测试 + jsdom/WebGL mock 渲染测试） |

## 迭代二五大功能

### 功能01：高级三维航迹规划
- 8 种可插拔规划策略：A\*、Dijkstra、**RRT、RRT\*、Hybrid A\***、**蚁群 ACO、粒子群 PSO、遗传 GA**
- 统一 `PathPlanner` 接口与算法注册表（`src/core/planners/`），随机算法用确定性 RNG（可复现）
- 支持全局规划与**局部重规划**、多航点任务（start→via→end）
- 每种算法独立参数面板，滑块**实时调节**（步长/目标偏置/重连半径、蚂蚁数/信息素因子、粒子惯性/学习因子、交叉变异概率等）
- “算法对比”页：同一环境/任务批量运行多算法，横向对比航程/耗时/节点/代价/暴露/约束满足率
- RRT 类算法记录采样树候选航迹，三维视图叠加显示

### 功能02：动态避障与在线重规划
- 移动障碍物（线性往返/折线巡逻）与突发威胁（按时间窗出现/消失），见 `DynamicEntity`
- `DynamicEnvironment` 提供时变碰撞、动态威胁场与**时空航段可行性**
- 在线触发条件：威胁进入预警 / 前瞻碰撞风险 / 偏航过大 / 剩余航程异常（均可独立开关并调阈值）
- 触发后执行**时空感知局部 RRT** 绕飞，自动拼接回原航线；冷却机制防抖
- 重规划事件记录：时刻、原因、前后局部代价、耗时；三维飘字 + 右上角提示
- 工具栏 💥 可在无人机前方即时投放突发威胁演示

### 功能03：动力学约束
- 约束项：最大转弯角、最大爬升角、最小步长、速度范围、最大加速度、最小转弯半径、最大姿态变化率
- 可选择在搜索过程中施加（RRT steer / Hybrid A\* 运动基元）或仅事后检查
- 约束报告：六类违反计数、综合满足率、违反点下标；三维视图红点高亮
- 碰撞感知的拉普拉斯**自动整形修正**（可开关）

### 功能04：高级平滑与跟踪
- 7 种平滑：折线松弛、三次 B 样条、**三次贝塞尔（Catmull-Rom）、三次多项式样条、Dubins（LSL/RSR/LSR/RSL）、Clothoid（回旋-圆弧-回旋，Fresnel 数值积分）**
- 速度规划增强：曲率限速 `v≤√(a/κ)` + 正反向加速度传播
- 平滑前后指标对比：航程、最大/平均曲率、最大转角/爬升角、最大速度/加速度/**抖动 jerk**
- 二阶轨迹跟踪仿真：横向/高度/航向/速度 RMS 误差与峰值；红色虚影可视化实际跟踪位置

### 功能05：可视化增强
- 动态威胁作用范围**实时更新**（脉冲圆柱、地面环）
- 移动障碍物**预测轨迹**虚线与速度箭头
- 局部重规划窗口与候选航迹叠加显示
- 重规划触发原因飘字提示
- 航迹**安全裕度颜色映射**（净空比 绿→红），动态威胁出现时回放中实时重着色

## 快速开始

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 产物在 dist/（Worker 独立 chunk）
npm run test       # 48 个单元/集成测试
npm run typecheck  # vue-tsc 严格类型检查
npm run preview
```

打开后自动完成一次全局规划并进入演示：
1. **⚡ 执行规划**，右上切换 8 种算法/7 种平滑，参数滑块实时观察航迹变化
2. 「算法对比」页批量对比各策略
3. 底部 **▶ 播放**：移动障碍横穿航线时自动触发在线局部重规划；t≈9s 突发防空出现
4. 工具栏 💥 可手动在无人机前方投放即时突发威胁
5. 「仿真评估」页查看约束满足率、平滑前后指标、跟踪误差、重规划事件

## 操作指南

- 视角：左键旋转 / 右键平移 / 滚轮缩放；轨道 / 俯视 / 跟随相机
- 编辑：左侧工具在地形上点击放置威胁/禁飞/建筑/移动障碍/航点；`Delete` 删除
- 移动障碍可在右侧面板改速度、巡逻点、出现时刻，或切换为突发威胁
- 快捷键 `空格` 播放暂停、`Esc` 退出编辑模式

## 架构

```
src/
├── core/
│   ├── terrain.ts / environment.ts         # 程序化地形、静态碰撞
│   ├── dynamic-environment.ts               # 时变动态环境（移动障碍/突发威胁/时空可行性）
│   ├── planner.ts                           # 体素 A*/Dijkstra（二叉堆、26 邻域、边采样）
│   ├── planners/                            # 功能01 算法注册表与 6 种新算法
│   │   ├── registry.ts  rrt.ts  hybrid-astar.ts
│   │   ├── aco.ts  pso.ts  ga.ts  corridor.ts
│   ├── dynamics.ts                          # 功能03 约束检查/扩展校验/自动修正
│   ├── smoothing.ts                         # 功能04 7 种平滑 + 曲率限速速度规划
│   ├── metrics.ts                           # 航程/曲率/转角/加速度/抖动指标
│   ├── tracking.ts                          # 功能04 二阶跟踪仿真
│   ├── replanning.ts                        # 功能02 触发检测 + 时空局部 RRT
│   ├── planning.ts                          # 多航段编排、平滑派发、多算法对比
│   ├── cost.ts / rng.ts
│   └── *.test.ts
├── three/                    # SceneRenderer 场景、拾取拖拽、动态叠加层
├── components/               # 工具条/视口/四个标签页/播放条
├── stores/                   # Pinia：scene（含动态实体）、sim（在线重规划/跟踪）
└── workers/planner.worker.ts # 规划 Worker（plan / compare）
```

数据流：`UI/拾取 → scene store → Worker(规划) → PlanResult → sim store →
平滑/速度规划/约束/指标 → PlanResult → Three 动画（RAIFF 中在线触发检测→局部 RRT→拼接轨迹）`

## 已知边界

- 全局规划在 t=0 静态口径下进行；移动障碍/突发威胁在回放期由在线局部重规划处理
- 元启发式算法（ACO/PSO/GA）采用切片走廊 + 分层 DP 修复，在走廊无法覆盖的极复杂绕行场景会如实报失败
- Clothoid/Dubins 为水平面圆弧模型，高度按弧长线性过渡；大转角相邻过近时自适应缩小转弯半径或回退折线
- 无头环境（无 GPU）由 48 个 Vitest 用例保证算法正确性，渲染建议本地浏览器运行
