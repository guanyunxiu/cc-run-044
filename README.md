# 无人机三维航迹规划与避障仿真系统（迭代二：高级避障与在线重规划）

浏览器端多无人机三维航迹规划与动态避障仿真：程序化地形、可插拔高级规划算法（A\*/Dijkstra/RRT/RRT\*/Hybrid A\*/蚁群/粒子群/遗传）、动态威胁与移动障碍、在线局部重规划、动力学约束检查与自动修正、B 样条/贝塞尔/多项式/Dubins/Clothoid 高级平滑、轨迹跟踪误差、WebGL 实时渲染与多机飞行回放。规划计算运行在 **Web Worker**，在线局部重规划在主线程按 4 Hz 触发，不阻塞渲染。

## 技术栈

| 层次 | 选型 |
| --- | --- |
| 语言 | TypeScript 5.6（strict） |
| 渲染 | Three.js 0.169 / WebGL2（自动回退 WebGL1） |
| 前端 | Vue 3.5（`<script setup>`） |
| 状态 | Pinia |
| 并行 | Web Worker（Vite `?worker` 独立分包） |
| 构建 | Vite 5 |
| 测试 | Vitest（node 算法测试 + jsdom/WebGL mock 渲染测试） |
| 监控 | Stats.js（FPS 面板）、Performance API（规划耗时） |

## 快速开始

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 产物在 dist/（Worker 独立 chunk）
npm run preview
npm run test       # 61 个单元/集成测试
npm run typecheck  # vue-tsc 严格类型检查
```

打开后默认场景（山地峡谷、3 静态威胁、1 禁飞区、2 建筑、1 巡逻移动障碍、1 突发威胁、**2 架交叉任务无人机**）会**自动完成多机全局规划**并进入可演示状态。勾选播放条「在线重规划」后播放，即可看到无人机在移动障碍接近时自动局部重规划。

## 迭代二功能对照

### 功能01：高级三维航迹规划

- **8 种可插拔规划策略**：`src/core/planners/` 下统一 `Planner` 接口 + 注册表
  - `astar` / `dijkstra`：三维体素 26 邻域 + 长步长（迭代一）
  - `rrt` / `rrtstar`：碰撞感知随机树扩展，RRT* 含近邻选父与重布线；目标偏置引导收敛，动力学转弯角软嵌入
  - `hybridastar`：位置栅格 × 离散航向状态，曲率/爬升受限运动基元，二叉堆搜索
  - `aco`：走廊航路点图上信息素概率选路（α/β/ρ/Q 可调）
  - `pso`：层节点编号粒子，惯性/认知/社会因子更新
  - `ga`：锦标赛选择 + 单点交叉 + 可行性引导变异
- **全局规划 + 局部重规划**：全局多机规划走 Worker；在线局部重规划（`core/replan.ts`）在主线程小窗口执行
- **多无人机 / 多目标点**：航点携带 `uavId`，`planMultiMission` 按机分组逐机规划，不同颜色渲染
- **模块化、可插拔、参数实时调节**：右侧面板按算法显示专属参数（RRT 步长/近邻半径、蚁群挥发率、PSO 因子、GA 变异率等）
- **策略切换与结果对比**：评估面板选择最多 4 种算法对首航段并行对比航程/代价/耗时

### 功能02：动态避障与在线重规划

- `src/core/dynamics.ts`：四类运动模型
  - `patrol` 多点往返巡逻、`linear` 匀速直线、`intercept` 朝参考航迹拦截、`burst` 定时出现并按生长时间膨胀（支持周期开关）
- `src/core/dynamicEnv.ts`：任意仿真时刻的时变环境快照（动态圆柱障碍带速度、突发威胁并入威胁场）
- **四类重规划触发条件**（`detectReplanTrigger`）：
  - 威胁进入安全裕度（沿预测轨迹扫描动态威胁距离）
  - 碰撞风险（无人机与障碍**双方时空相遇**预测，时间窗可调）
  - 偏航过大（实测跟踪航向 vs 参考航向）
  - 剩余航程异常（剩余航程/直线距离绕航倍率）
- **动态障碍预测避让**：环境快照保留障碍速度，碰撞检测按 `atTime` 线性外推
- **局部重规划**：起点取前瞻点、目标取窗口内最远自由参考点，主算法 + RRT 候选；按弧长对齐时钟无缝拼接
- **前后航迹与代价对比**：`ReplanEvent` 记录旧/新局部航迹、代价变化、耗时、原因、实体；3D 窗口内绿线=新、红线=旧、黄线=候选；右上角 Toast 与评估面板事件流

### 功能03：动力学约束（`src/core/kinematics.ts`）

- 参数：最大转弯角、最大爬升角、最小步长、速度范围、最大加速度、最小转弯半径、姿态变化限
- **可行性检查**：逐航段输出 `ConstraintReport`（违反类型/位置/实际值/限值）与约束满足率
- **自动修正**（`repairPath`，碰撞感知）：过短航段合并、大转角/大爬升折点角平分线插入
- **违反高亮**：碰撞/转弯/爬升违反点在 3D 航迹上以红色小球标记
- 规划层软约束：RRT 扩展与 Hybrid A* 运动基元在生成时即过滤超限动作

### 功能04：高级平滑与跟踪

- 平滑：折线松弛、三次 B 样条（迭代一）+ **贝塞尔（G1 连续）、Catmull-Rom 多项式、解析 Dubins CSC（LSL/RSR/LSR/RSL 取最短）、Clothoid 风格曲率过渡**；全部逐段碰撞复核并自动回退
- **速度规划**：弧长加密 + 梯形/三角速度剖面，加速度受动力学上限约束
- **轨迹跟踪**（`core/tracking.ts`）：速度一阶惯性 + 航向跟随（限加速度/偏航角速度）模型，离线推演实际轨迹
- **跟踪可视化**：红色实际轨迹叠加白色参考轨迹；评估面板显示平均/最大位置误差、平均航向误差
- **平滑前后指标对比**：航程、最大/平均曲率、最大转角、最大加速度、最大抖动（jerk）、平均速度

### 功能05：避障可视化增强

- 动态威胁作用范围随仿真时间实时更新（突发威胁脉冲透明度 + 半径生长）
- 移动障碍黄色虚线**预测轨迹**（按运动模型 + 预测时长，2 Hz 刷新）
- 重规划触发原因 3D 文字精灵 + 光柱 + 右上角 Toast
- 局部重规划窗口：起/终点标记球、新旧航迹、候选航迹
- **安全裕度颜色映射**：航迹顶点可在「威胁强度绿→红」与「净空红→黄→绿」两种映射间切换
- 多机不同主题色（航点/航迹/无人机一致着色）

## 操作指南

- **视角**：左键旋转 / 右键平移 / 滚轮缩放；左侧工具条切换轨道/俯视/跟随。
- **编辑环境**：添加模式下点击地形放置威胁/禁飞/建筑/**移动障碍**/航点（归属当前活动无人机）；选择模式可拖拽，右侧调参，`Delete` 删除。
- **多机**：环境编辑顶部切换活动无人机（后续添加的航点归属于它），可增删无人机。
- **动态实体**：选中后可在右侧切换移动障碍/动态威胁/突发威胁与运动模型，设置巡逻速度、速度向量、出现时刻/周期、预测时长。
- **规划**：右上「⚡ 执行规划」为全部无人机全局规划；算法/平滑/权重/约束实时可调。
- **在线对抗**：播放条勾选「在线重规划」后播放；触发阈值在规划参数面板调整。
- **回放**：播放/暂停/回起点/0.5×~8×/拖拽时间轴（`空格`、`Esc`）。
- **导出**：场景 JSON（v2.0，自动兼容 v1.0 配置）、航迹 CSV。

## 架构

```
src/
├── core/                       # 纯算法层（无 DOM，Worker 直接复用）
│   ├── terrain.ts              #   程序化 DEM
│   ├── environment.ts          #   碰撞/威胁场/禁飞场/动态圆柱/预测碰撞/净空
│   ├── dynamics.ts             #   动态实体运动模型 + 状态/预测
│   ├── dynamicEnv.ts           #   t 时刻环境快照构建
│   ├── planner.ts              #   三维体素 A*/Dijkstra
│   ├── planners/               #   可插拔规划器
│   │   ├── types.ts            #     Planner 接口/注册表/走廊图/代价工具
│   │   ├── grid.ts             #     A*/Dijkstra 适配器
│   │   ├── rrt.ts              #     RRT / RRT*
│   │   ├── hybrid.ts           #     Hybrid A*
│   │   └── swarm.ts            #     蚁群 / 粒子群 / 遗传
│   ├── smoothing.ts            #   折线/B样条/加密/梯形速度
│   ├── advancedSmoothing.ts    #   贝塞尔/多项式/Dubins/Clothoid
│   ├── kinematics.ts           #   动力学检查/修复/指标/安全裕度
│   ├── tracking.ts             #   轨迹跟踪模型与误差统计
│   ├── replan.ts               #   触发检测 + 局部重规划 + 候选/代价对比
│   ├── planning.ts             #   多机任务编排、平滑/修复/统计
│   └── cost.ts                 #   分段代价与累积曲线
├── workers/planner.worker.ts   # plan / plan-multi / compare / trajectory
├── three/
│   ├── factory.ts              # 地形/实体/动态实体/无人机/航迹工厂
│   └── SceneRenderer.ts        # 多机渲染、动态更新、重规划叠加、拾取拖拽
├── stores/
│   ├── scene.ts                # 场景要素（含动态实体、无人机、迁移 v1 配置）
│   └── sim.ts                  # 多机规划调度、时钟、跟踪、在线重规划循环
└── components/                 # 工具条/视口/三个标签页/播放条/图表
```

数据流：`UI → scene store → Worker(planMultiMission) → 每机 PlanResult（约束报告/指标/候选）→ 速度轨迹 + 跟踪仿真 → sim.uavStates → SceneRenderer`；播放时渲染循环按 4 Hz 以**当前动态环境快照**驱动 `tickOnlineReplan`，局部重规划结果按弧长对齐时钟拼接回对应无人机轨迹。

## 已知边界

- 动态障碍为竖直圆柱（带速度预测），静态障碍为盒体、威胁/禁飞为圆柱；复杂多边形可在 `Environment` 扩展。
- 群智算法（ACO/PSO/GA）基于走廊航路点图，在极端迷宫中可能无可行序列，此时自动回退 A*（可关闭）。
- 在线重规划为单步前瞻反应式（非博弈/MPC），高密度动态场景可调小最小间隔与前瞻距离。
- 无头环境（无 GPU）由测试保证算法正确性；真实渲染建议在本地浏览器运行。
